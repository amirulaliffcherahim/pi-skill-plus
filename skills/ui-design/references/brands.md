# Brand design-system references

A design-system write-up per brand (YAML tokens + prose rationale) lives upstream in VoltAgent/awesome-design-md (MIT): `https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/<name>/DESIGN.md`. Fetch ONE when the user names a brand or asks for a feel like it.

## How to use
- Learn the **structure**: how colors, type scale, spacing, radius, elevation and components are organised as tokens, and the one-line voice summary at the top.
- Borrow principles (e.g. photography-first, one interactive color, chrome recedes), not the identity. Never copy a brand's logo, name, wordmark, exact palette-plus-type combination or trademarks into the user's product.
- These are third-party analyses, not official brand guidelines.
